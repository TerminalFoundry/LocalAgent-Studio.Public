01
Observer + analyst, not one agent
Gothi records — normalizing every IDE event into structured records with rule-based classification, zero LLM dependency. Gethli reasons — synthesizing session analysis, extracting claims with evidence citations, producing verdicts. Separation of concerns enforced architecturally.
02
Claim grounding against reality
Every synthesis claim is verified against the actual git diff — not against what the AI said it did. Five verdict taxonomy: verified, weak, unverified, contradicted, fabricated. Unclaimed security-relevant changes are flagged automatically. This is audit infrastructure, not developer feedback.
03
Adaptive tier system
Auto-detects available compute and selects the appropriate model tier. Tier 4 — deterministic synthesis with zero LLM dependency — means the governance layer remains fully functional even with no AI inference available. You cannot break the audit trail by losing the model.
04
Six-dimension implementation scoring
Plan adherence, phase completion, incremental improvement, claim support, implementation fidelity, documentation coverage — scored 0–100 and graded S through F. Persisted to SQLite with 30-day retention. Every session produces a verifiable record.
